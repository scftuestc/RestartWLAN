# RestartWLAN — 网卡重启小工具

针对一台安装了 MediaTek MT7922 (Wi-Fi 6E) 无线网卡的 Windows 11 笔记本的网络自愈脚本。

## 背景

2026 年 10 月的 Windows 累积更新(KB5129195)触发了该网卡的两个丢包问题:

1. 网卡高级属性「省电」= Auto 时, 到路由器出现 40%~50% 的突发丢包;
2. 即使已禁用省电, 每次开机后驱动仍会进入丢包状态, 需要一次「运行时重启网卡」才能恢复。

本工具把「诊断 + 修复」做成一条交互式流程。

## 功能流程(六步, 每步 y/N 确认)

1. **网卡信息** — 硬件名称、驱动版本、支持频段、当前连接(SSID/频段/协议/信号);
2. **丢包测试(前)** — 向路由器发 20 个包统计丢包;
3. **国内网站连通性** — baidu / bilibili / qq / taobao 各 4 包, 汇总平均延迟;
4. **省电模式切换(可选)** — 已禁用 ↔ Auto;
5. **重启网卡** — 只重启无线网卡(WLAN), 不动有线网卡;
6. **丢包测试(后)** — 复测并给出结论。

## 使用方法

双击 `RestartWLAN.bat` → 在 UAC 弹窗点「是」→ 按提示输入 y 继续,
回车或 N 随时退出, 结尾按 Enter 关闭窗口。

## 注意事项

- **本脚本文件为 GBK(ANSI / CP936)编码** —— 用 Windows 记事本可直接查看;
  用 VS Code 等编辑器请手动选择 GBK/GB2312 编码, 否则中文会显示乱码。
  也不要把它转存为 UTF-8, 否则 cmd 运行时中文全部乱码。
- 只重启 **WLAN 无线网卡**(网卡名硬编码在脚本里), 有线网卡不受影响。
- 路由器地址硬编码为 `192.168.0.1`, 更换网络环境后请修改脚本开头的 `ROUTER` 变量。
- 需要管理员权限(脚本会自动请求提权)。
- 本机已知「省电 = Auto」会丢包, 日常请保持「已禁用」; Auto 仅用于验证
  Windows 更新是否修复了该 bug。
