# RestartWLAN — 网卡重启小工具

Windows 下的小脚本: 一键完成「丢包诊断 → 重启无线网卡 → 复测」,
用于应对无线网卡间歇性丢包的情况(网页时卡时不卡、游戏加速器报网络异常等)。

## 功能流程(六步, 每步 y/N 确认)

1. **网卡信息** — 硬件名称、驱动版本、支持频段、当前连接(SSID/频段/协议/信号);
2. **丢包测试(前)** — 向路由器发 20 个包统计丢包;
3. **国内网站连通性** — baidu / bilibili / qq / taobao 各 4 包, 汇总平均延迟;
4. **省电模式切换(可选)** 
5. **重启网卡** 
6. **丢包测试(后)** — 复测并给出结论。

## 使用方法
下载`RestartWLAN.bat`文件  
双击 `RestartWLAN.bat` → 在 UAC 弹窗点「是」→ 按提示输入 y 继续,
回车或 N 随时退出, 结尾按 Enter 关闭窗口。

## 注意事项

- **脚本文件为 GBK(ANSI / CP936)编码**: 用记事本可直接查看; 用 VS Code
  等编辑器请选择 GBK/GB2312 编码打开, 不要转存为 UTF-8(否则 cmd 下中文乱码)。
- 只重启名无线网卡; 路由器地址硬编码为 `192.168.0.1`,
  更换网络环境请修改脚本开头的 `ROUTER` 变量。
- 需要管理员权限(脚本会自动请求提权)。
- 无线网卡的「省电 = Auto」模式已知可能会导致丢包, 日常保持「已禁用」即可。
